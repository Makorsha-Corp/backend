### Dead-code flag — do this before testing

A static reference scan (across `app/`, `tests/`, `alembic/`, `scripts/`) found **86
callables that are never called, imported, or named in a string** outside their own
definition. They are marked `⚠️ [possibly unused — verify before testing]` in both
checklists and enumerated with `file:line` refs and an IDE workflow (Find Usages →
delete or keep) in [`dead-code-removal-checklist.md`](dead-code-removal-checklist.md).
The scan is heuristic (misses dynamic dispatch, squashed-migration callers) — verify
each in the IDE, then delete it or annotate why it stays. Spot-checked confirmed-dead:
the legacy `post_purchase_order_to_machine` / `post_purchase_order_to_storage`
PO-inventory functions and the `SalesService.create_sales_order` wrapper.

All three checklist files are generated by the scripts in
[`_generators/`](_generators/README.md) — rerun them after changes under the six
layer directories.

### How to work the checklist

1. Pick a file (by-layer) or a domain (by-domain).
2. Write unit tests for each unchecked function; tick the box in the same PR.
3. Skip nothing silently — if a function is not worth a unit test (pure re-export,
   trivial `__init__`, framework `dispatch`), tick it and note `n/a — <reason>`.
